# Experiments: Cross-Edge Generators in Commutators

## Goal

Determine whether a cross-edge generator e_{ij} (with v_i ∈ supp(w₁) and
v_j ∈ supp(w₂)) always appears in NF([w₁,w₂]) when vertex supports cross
hyperedge boundaries, and whether the commutator is forced to be non-central
in such cases.

All computations use the R1/R2/R3 rewriting system. Words are given as
space-separated signed generators; uppercase = inverse.

---

|-----|-------------------------|-----------|-----------|------------|----------|----------------------|----------|
| 1A  | Path {ab,bc,cd}         | a b       | c d       | no         | no       | e_{ab}, e_{cd}       | F        |

## Experiment 1A — Path graph, disjoint supports {a,b} vs {c,d}

**Hypergraph:** vertices (a,b,c,d), maximal edges {a,b}, {b,c}, {c,d}.
E2 = {{a,b},{b,c},{c,d}}, E3 = ∅.

```
w₁ = a b       supp(w₁) = {a, b}
w₂ = c d       supp(w₂) = {c, d}
```

Supports are disjoint. The only cross-support E2-edge is {b,c} (b ∈ S₁, c ∈ S₂).

```
NF(w₁)  [4 steps]  = a b
NF(w₂)  [4 steps]  = c d

NF([w₁,w₂])  [22 steps]:
  a⁻¹ b⁻¹ e_{ab}⁻¹  |  c⁻¹ d⁻¹ e_{cd}⁻¹  |  a b  |  c d

NF([[w₁,w₂], w₁])  [57 steps]:   non-trivial (8 blocks)
NF([[w₁,w₂], w₂])  [55 steps]:   non-trivial (10 blocks)
```

**Cross-edge generators present:** e_{ab}⁻¹ (block 1), e_{cd}⁻¹ (block 2).

**Surprise: e_{bc} is absent.** Even though {b,c} is the only E2-edge crossing
the two supports, it does not appear in NF([w₁,w₂]). Checking sub-commutators
reveals why: e_{bc} does appear in NF([a·b, c]) and NF([b, c·d]) individually,
but it cancels when the full four-letter commutator is assembled. Instead only
the within-support symbols e_{ab} and e_{cd} survive.

The commutator is **not central** (both nested commutators non-trivial).

**Witness structure:** blocks 1 and 2 contain e_{ab} and e_{cd} respectively.
For e_{ab}: {a,b,c} ∉ E3 and {a,b,d} ∉ E3 (no 3-edges exist) ✓
For e_{cd}: {c,d,a} ∉ E3 and {c,d,b} ∉ E3 ✓

## Experiment 1B — Path graph, overlapping supports {a,b} vs {b,c}

**Hypergraph:** same path graph.

```
w₁ = a b       supp(w₁) = {a, b}
w₂ = b c       supp(w₂) = {b, c}
```

Shared vertex: b (in edge). Exclusive: a (in {a,b}), c (in {b,c}). The pair
{a,c} is NOT in E2, so there is no cross-edge e_{ac}.

```
NF(w₁)  [4 steps]  = a b
NF(w₂)  [4 steps]  = b c

NF([w₁,w₂])  [39 steps]:
  a⁻¹ e_{ab}⁻¹  |  c⁻¹ e_{bc}  |  a e_{ab}  |  e_{ab}  |  c

NF([[w₁,w₂], w₁])  [241 steps]:   non-trivial (13 blocks)
NF([[w₁,w₂], w₂])  [278 steps]:   non-trivial (15 blocks)
```

**Cross-edge generators present:** e_{ab} (blocks 1, 3, 4) and e_{bc} (block 2).
Here e_{bc} DOES appear — the shared generator b is in both edges, producing a
richer interaction than Exp 1A where e_{bc} cancelled out.

The commutator is **not central**.

**Witness structure:** e_{ab} appears with vertex c (block 1: a⁻¹ e_{ab}⁻¹ with
adjacent c-block). {a,b,c} ∉ E3 ✓. Similarly e_{bc} with vertex a: {a,b,c}
∉ E3 ✓.

## Experiment 2A — Triangle, conjugated generators ⚑ KEY LEMMA FLAG

**Hypergraph:** triangle, vertices (a,b,c), maximal edge {a,b,c}.
E2 = {{a,b},{a,c},{b,c}}, E3 = {{a,b,c}}.

```
w₁ = a b A     (= a·b·a⁻¹)    supp_V(w₁) = {a, b}
w₂ = a c A     (= a·c·a⁻¹)    supp_V(w₂) = {a, c}
```

Cross-support E2-edge: {b,c} (b ∈ S₁ \ S₂, c ∈ S₂ \ S₁).

```
NF(w₁)  [11 steps]  = b e_{ab}
NF(w₂)  [11 steps]  = c e_{ac}

NF([w₁,w₂])  [71 steps]:
  e_{bc}

NF([[w₁,w₂], w₁])  [228 steps]:  ε (identity)
NF([[w₁,w₂], w₂])  [243 steps]:  ε (identity)
```

**Cross-edge generators present:** only e_{bc}⁺¹.

**⚑ KEY LEMMA FLAG:** [w₁,w₂] = e_{bc} ≠ ε, but BOTH nested commutators are
the identity. The commutator IS central. The supports cross the hyperedge
boundary ({b,c} ∈ E2, b ∈ S₁, c ∈ S₂), yet [w₁,w₂] is central.

**Why?** Because {a,b,c} ∈ E3. This forces [e_{bc}, a] = 1, [e_{bc}, b] = 1,
[e_{bc}, c] = 1 — so e_{bc} is central in G(χ). The cross-edge is produced
but lands in the center. The 3-edge kills all non-centrality.

**Baudisch class: H (Heisenberg).** The subgroup ⟨w₁, w₂⟩ is 2-step nilpotent
with center generated by e_{bc}.

## Experiment 2B — Triangle, power-prefixed generators ⚑ KEY LEMMA FLAG

**Hypergraph:** same triangle.

```
w₁ = a a b     (= a²·b)        supp_V(w₁) = {a, b}
w₂ = a a c     (= a²·c)        supp_V(w₂) = {a, c}
```

```
NF(w₁)  [13 steps]  = a b e_{ab} | a
NF(w₂)  [13 steps]  = a c e_{ac} | a

NF([w₁,w₂])  [64 steps]:
  e_{ab}⁻¹ e_{ac} e_{bc}  |  e_{ab}⁻¹ e_{ac}

NF([[w₁,w₂], w₁])  [216 steps]:  ε (identity)
NF([[w₁,w₂], w₂])  [222 steps]:  ε (identity)
```

**Cross-edge generators present:** e_{ab}, e_{ac}, e_{bc} — all three E2-symbols
of the triangle, in both blocks. The commutator is more complex than Exp 2A
(two blocks instead of one singleton) but is still **central**.

**⚑ KEY LEMMA FLAG (same as 2A):** [w₁,w₂] ≠ ε and supports cross, but the
commutator is central. Powers of a introduce additional e_{ab} and e_{ac} terms
but do not escape the center, because all E2-symbols are central in the triangle
(every triple {v_i,v_j,v_k} is in E3 = {{a,b,c}}).

**Baudisch class: H.** Same reason as 2A: G(χ) on the triangle has a central
augmented alphabet, making every commutator of any two words central.

## Experiment 3 — Two overlapping 3-edges, boundary crossing

**Hypergraph:** vertices (a,b,c,d), maximal edges {a,b,c} and {b,c,d}.
E2 = {{a,b},{a,c},{b,c},{b,d},{c,d}}, E3 = {{a,b,c},{b,c,d}}.
Note: {a,b,c,d} and {a,b,d}, {a,c,d} are NOT edges.

```
w₁ = a b       supp(w₁) = {a, b}
w₂ = c d       supp(w₂) = {c, d}
```

Cross-support E2-edges: {a,c}, {a,d}(?), {b,c}, {b,d}.
Check: {a,d} ∉ E2 (no edge between a and d). So cross-support E2 = {{a,c},{b,c},{b,d}}.

**Centrality of edge symbols (confirmed by computation):**

| Symbol  | [e, a] | [e, b] | [e, c] | [e, d] | Central? |
|---------|--------|--------|--------|--------|----------|
| e_{bc}  | ε      | ε      | ε      | ε      | **yes** (both {abc} and {bcd} ∈ E3) |
| e_{ab}  | ε      | ε      | ε      | ≠ ε    | no  ({a,b,d} ∉ E3) |
| e_{ac}  | ε      | ε      | ε      | ≠ ε    | no  ({a,c,d} ∉ E3) |
| e_{bd}  | ≠ ε    | ε      | ε      | ε      | no  ({a,b,d} ∉ E3) |
| e_{cd}  | ≠ ε    | ε      | ε      | ε      | no  ({a,c,d} ∉ E3) |

```
NF(w₁)  [4 steps]  = a b
NF(w₂)  [4 steps]  = c d

NF([w₁,w₂])  [52 steps]:
  a⁻¹ e_{ab}⁻¹ e_{bc}  |  d⁻¹ e_{bd}  |  a e_{ab} e_{ac}  |  d

NF([[w₁,w₂], w₁])  [276 steps]:   non-trivial (11 blocks)
NF([[w₁,w₂], w₂])  [336 steps]:   non-trivial (11 blocks)
```

**Cross-edge generators present:** e_{bc} (central, block 1), e_{ab} (blocks 1,3),
e_{bd} (block 2), e_{ac} (block 3). Note e_{cd} does not appear.

The commutator is **not central**.

**Witness structure:** despite e_{bc} being central and appearing in block 1,
the non-centrality is carried by e_{ab}, e_{ac}, e_{bd}:

- e_{ab} with d: {a,b,d} ∉ E3 ✓ → [e_{ab}, d] ≠ 1
- e_{ac} with d: {a,c,d} ∉ E3 ✓ → [e_{ac}, d] ≠ 1
- e_{bd} with a: {a,b,d} ∉ E3 ✓ → [e_{bd}, a] ≠ 1

The 3-edges kill some cross-edge commutators (e_{bc} becomes central, e_{ab}
commutes with c, e_{bd} commutes with c) but at least one non-central cross-edge
always survives because {a,b,c,d} is not a single edge.

**Baudisch class: F** (free-like). The nested commutators are non-trivial; the
subgroup ⟨w₁,w₂⟩ is not 2-nilpotent.

## Cross-Experiment Analysis

### 1. Does e_{bc} always appear when b ∈ S₁, c ∈ S₂, {b,c} ∈ E2?

**No.** Exp 1A has b ∈ S₁ and c ∈ S₂ with {b,c} ∈ E2, yet e_{bc} does not
appear in NF([w₁,w₂]). The cross-edge cancels when the full four-factor
commutator is formed. Individual sub-commutators [ab,c] and [b,cd] each
produce e_{bc}, but it cancels across the product.

### 2. Does crossing hyperedge boundaries force non-centrality?

**No — not always.** Experiments 2A and 2B are explicit counterexamples:
supports cross the {b,c} boundary but [w₁,w₂] is central because {a,b,c} ∈ E3
makes e_{bc} central in G(χ). The Key Lemma would need an additional condition
beyond "supports cross some E2-edge."

### 3. Witness hyper-letter structure

In every non-central case, the non-centrality is witnessed by a hyper-letter
containing e_{ij} where **there exists v_k in the vertex alphabet such that
{v_i, v_j, v_k} ∉ E3**. Specifically:

| Experiment | Non-central e_{ij} | Failing triple           |
|------------|--------------------|--------------------------|
| 1A         | e_{ab}             | {a,b,c} ∉ E3 (no E3)    |
| 1A         | e_{cd}             | {c,d,a} ∉ E3 (no E3)    |
| 1B         | e_{ab}             | {a,b,c} ∉ E3 (no E3)    |
| 1B         | e_{bc}             | {a,b,c} ∉ E3 (no E3)    |
| 3          | e_{ab}             | {a,b,d} ∉ E3             |
| 3          | e_{ac}             | {a,c,d} ∉ E3             |
| 3          | e_{bd}             | {a,b,d} ∉ E3             |

In Exp 3, e_{bc} also appears but is inert (it is fully central and does not
drive non-centrality). The pattern holds: **every non-central e_{ij} in the
witness block is paired with some v_k where {v_i,v_j,v_k} ∉ E3**.

In Exp 2A and 2B the only cross-edge is e_{bc} and {a,b,c} ∈ E3 — so no
failing triple exists, and e_{bc} is central. This is precisely why the Key
Lemma condition must require at least one failing triple, not just an E2-edge
crossing.

### 4. Key Lemma status

> "If [w₁,w₂] ≠ 1 but [[w₁,w₂],w₁] = [[w₁,w₂],w₂] = 1 despite supports
> crossing boundaries — flag as potential counterexample."

**Flagged: Experiments 2A and 2B.** Both satisfy [w₁,w₂] ≠ 1, nested
commutators = ε, and supports crossing E2-boundaries. These are not
counterexamples to the Key Lemma as stated if the Lemma already requires a
non-central cross-edge (i.e., requires the failing-triple condition). They
**are** counterexamples if the Lemma states only "supports crossing forces
non-centrality." The data suggests the correct hypothesis is:

> *[w₁,w₂] is non-central iff there exists an E2-edge {v_i,v_j} with
> v_i ∈ supp_V(w₁), v_j ∈ supp_V(w₂) AND some v_k with {v_i,v_j,v_k} ∉ E3.*
